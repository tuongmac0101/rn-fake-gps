## TESTING GUIDE

### 1. LOGIN & OVERVIEW
- Use the credentials above to sign in
- The app will load with B2B sales order management interface
- After login, you'll see the home screen with quick actions and statistics

### 2. KEY FEATURES TO TEST

**Orders Management:**
- View existing orders in "Order Management" tab
- Create new sales orders (Xuất bán)
- Create sample orders (Xuất mẫu)
- Create consignment orders (Xuất ký gửi)
- View order details and summaries
- Manage return orders (Đơn trả lại)
- Approve orders (if you have approval permissions)

**Customer Management:**
- Browse customer list
- View customer details and information
- Manage customer delivery addresses
- Search and filter customers

**Product & Inventory:**
- Search for products (SKU)
- View product information
- Check real-time stock levels
- Select price types for different customer segments

**Shipment Management:**
- View shipment details
- Manage shipment plans
- Delivery allocation
- Delivery options

**Recall Management:**
- Create product recall requests
- Manage recall product lists
- View recall summaries

**Payment & Shipping:**
- Select payment methods
- Calculate shipping fees
- View payment details

### 3. CREATE A TEST ORDER
1. Navigate to Home screen
2. Tap "Tạo đơn xuất bán" (Create Sale Order) button
3. Select a branch (if multiple branches available)
4. Select a customer from the customer list
5. Search and add products (SKU) to the order
6. Select price type if needed
7. Add delivery address
8. Review order summary
9. Submit the order

### 4. IMPORTANT NOTES

- **App Type:** This is a B2B enterprise application designed for FMCG (Fast-Moving Consumer Goods), pharmaceutical, and construction material distribution companies
- **Test Account:** The provided test account contains sample data for demonstration purposes
- **Internet Connection:** Internet connection is required for full functionality as the app syncs with the company's central management system
- **Authentication:** The app uses SSO (Single Sign-On) authentication
- **Language Support:** The app supports multiple languages (Vietnamese, English)
- **Theme:** Supports Light/Dark mode
